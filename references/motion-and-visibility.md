# 楼层、交互和设备运动

货物数量、正交视图与爆炸图的操作状态、复原和验收统一见 [场景操作](scene-interaction.md)。

## 多余货物与楼层残留

为每个实体维护 `buildingId`、`buildingFloorId`、`ownerId`、`role`、`visibilityScope`。楼层号不是用世界 Y 坐标临时猜的：贯通立库可能跨层，却只归首层/全部视图。附属货物、轨道、护栏、提升机外壳、运动平台、动画货物都继承明确主人。

每次切换从统一状态计算显隐，而不是在上次效果上不断叠加。按“仓库 × 归属 × 货物/墙体开关”分组或建立实例可见性映射；混入同一个 InstancedMesh 后仅隐藏父组会留下其他层的零件。动态实例和后来生成的货物必须执行相同过滤。

排查多余货物：CAD 自带托盘 + 资产内置货物 + 自动填货 + 运行时生成是否重复；`sourceHandle + nestedPath` 是否去重；旧模型在异步重建后是否残留。使用稳定随机种子控制部分货位占用，刷新不应凭空增减。0% 货架占用不等于删除图纸明确标出的暂存货物。

验收按“全部 → 首层 → 上层 → 另一仓库 → 全部”走一遍，比较实际可见实体 ID，含实例批次和动画中途状态。历史仓库二二层残留立库的问题，要检查附属轨道/货物的归属，不能只隐藏货架主模型。

## 墙挡视线、透明壳和无边背景

“看仓库一地狼被墙挡住”先检查墙体组、内墙/外墙分类和聚焦相机路线。聚焦时可隐藏用户允许的遮挡外墙或提供明确墙体开关；不把车辆抬高穿墙，不全局把场景材质变透明。物体归属可见但被遮挡，与被显隐规则隐藏是两种不同问题。

用户要求取消淡化后，设置其他层 `visible=false` 并恢复曾改过的 opacity、transparent、depthWrite；共享材质先克隆或统一恢复，避免一层调整污染全站。提升机壳体不透明时检查 `transparent=false`、`opacity=1`、transmission/alphaTest/alphaMap 及透明排序；动画平台和开口仍须可见，不把开口封成实体墙。

移除环境底面时保留真实建筑楼板、设备支撑和月台。背景用 renderer 的背景色/环境；影子承接平面若会显露边缘，也需按用户的无边要求处理。

## 父子运动关系

先建立关节轴、父级、原始矩阵和限位，再做动画；所有增量相对 rest pose，不能每帧累加漂移。单个资产多次实例化后不能共享活动节点。通用运动轴来自资产接口/轨道，不能硬编码全局 X/Z。

历史智狼大车的正确关系：**钢架沿平行货架的轨道行走；狼在钢架内上下运动；钢架带着狼一起走；货物跟随狼的承载接口**。建议层级 `行走根 → 钢架 → 升降狼 → 货物接口`，不要给整机做垂直于货架的横移，也不要分别写世界位置导致上下机构与钢架脱离。该关系针对已确认机型，不套用到所有穿梭车。

智狼库的搭配、图示位置去重、立柱与承载器分开调高、AGV 转弯及点击跟随，按 [智狼库专用参考](zhilang-layout.md) 核对。参考中的展示动画不等于货物交接或工程级交通调度已实现。

提升机移动平台，外壳固定；机械臂按关节链和夹持点带货；叉车行走与货叉升降分开；轮子与滚筒可按行进距离转动。列出每类可动件的实际支持状态；“全部会动”不能只实现车辆平移而遗漏提升机/机械臂。

帧时间使用 `dt × speed`，暂停冻结仿真时钟和所有设备/货物，但视角仍可操作。隐藏/失焦后的大时间间隔要限制或按固定仿真步长处理；倍速保持任务逻辑与空间路径，不只是让轮子更快。

## 出入库与货物交接

货物要有明确来源、去向、承载者和任务状态。用户授权按模型安排时，先按真实设备位置建立演示交接点并记录为演示路线；若用户说由其指定路线，未收到路线前不能冒充实际工艺。

完整演示可按已确认设备编排：货车/卸货点 → 叉车 → 料箱/暂存区 → 小车 → 输送线/扫描工位 → 提升机 → 入库交接点；出库反向或使用另一路线。机械臂产线也要有输入缓冲、夹取、作业/放置、输出输送及终点。模型没有货车/月台等时需补充有依据的演示资产或明确缺失，不能称短距离往返为完整流程。

每个任务使用状态机：等待货物 → 前往取货 → 对位 → 取货 → 载货移动 → 对位放货 → 释放 → 离开。接驳需要设备 ready、位置/高度匹配、目标空闲，完成后才移交；输送段按长度和速度推进，转向交给移载工位。

同一货物任一时刻只归一个 carrier/工位。取货时对齐载货端口与货物底部/拾取锚点，改变 parent 时维护世界变换和尺寸；放货时解除父子关系，落到目标支撑面。非均匀缩放父级可能引入剪切，优先规范载货根节点缩放，必要时显式求解世界变换，不能假定 `attach()` 在任意缩放链下无误。

静态满/部分库效果与演示流转货物分开。用户允许库存不真实增减时，终端回收/起点再生仍要在合理缓冲点完成，不能在视野里瞬移或越跑越多。使用有界对象池。只复用静态库位外观，不伪称真实库存仿真、避碰或机器人控制已完成。
