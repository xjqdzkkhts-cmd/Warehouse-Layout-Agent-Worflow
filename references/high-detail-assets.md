# 高精度资产派生

统一高精度是用户固定偏好；本包只提供高精度模型。项目中每个资产记录 `sourceLibrary`、`modelSha256`，派生件额外记录源件哈希和生成脚本。已授权的代用只适用于授权项目和范围，不自动扩展到其他设备或新项目。

初始化和迁移时，以高精度库覆盖同 ID 的低模引用；检查实际加载路径，避免“目录已有高精度、运行时仍加载低模”。重复货架也需由高精度立柱、横梁、支撑等零件重组，不能只升级独立设备而遗漏参数化几何。普通辊筒不在53个源资产中，使用下述高精度派生工具，不能回退低模 `roller-conveyor`。

53 个高精度 GLB 带原有动画与 spec，位于 assets/asset-library-high；低保真库已删除。不得覆盖源库。高精度是本库相对分类，不是制造精度保证。优先检查实际三角数、材质、节点、单位、接地和真实承载面。

已交付的高精度连续输送线：campus-example/tools/high-conveyors.mjs，prepareHighConveyors(forkGLTF,chainGLTF,sourceSpecs) 返回 rollerLine(id,width,length,height) 和 chainLine(...)；单位米。导出使用同目录 build_assets.mjs 的 GLTFExporter/FileReader 兼容方式。函数当前适配包内 fork-roller-conveyor、chain-short 的指定节点，其他源资产需重新校验，不能按名字盲套。

辊筒复用端部，延长中间轴段，固定直径与间距；脚、开放型材、螺母和电机按结构组合。链条复用链板/销轴，按数量适配长度而不是拉长链节；机架跨度、地脚、回程链和电机独立适配。小于结构容纳尺寸的设备需另建，不能负缩放。
端口来自实际承载几何；不能用整体 bounding box 最高点当承载面。链板中间收腰低于端部承托点，射线应取真实承载凸部。每种长度检查底部、占地、两端范围、承载高度；所有实例仍验证 CAD 世界位置。
案例中 35 段辊筒、48 段链式、0.8 m 高度及 976 次射线仅是回归数据。新尺寸生成后必须重新检查。静态合并同材质、焊接重复顶点、实例化共享模型；活动节点不得误合并。
