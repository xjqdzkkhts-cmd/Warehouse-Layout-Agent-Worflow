# 园区与仓库范围

先依据用户需求、总平面/楼层标题、用地边界和建筑内容，记录 campus、warehouse 或 mixed。多栋仓库不自动证明存在完整园区图；已明确范围不重复询问。

- 园区：建设图示建筑及设备，同时包含绿化、园区内道路、硬地、停车、围墙和出入口。图纸涉及园区外道路时也按可见范围建设，单列 publicRoads，不得被用地边界裁掉，不虚构延伸路网。
- 仓库：按仓库/楼层图建设建筑与设备，不凭空补园区；图示接驳月台、道路和绿化按授权范围保留。
- 混合图：分别识别总平面和详细平面的单位、比例、坐标，可靠配准后合成，防止重复建设同栋建筑。

记录每项来源句柄/图层、范围角色及已生成/未提供/待核对状态。用地边界与显示范围分开，显示范围包括图示外部道路。建筑隔离时隐藏环境，总览恢复；镜头与阴影覆盖完整显示范围。

按 [场地规则](campus-surfaces.md) 分别校验内外道路、绿化与硬地的面积和重叠，园区外图示道路不计作错误越界。室外按沥青、混凝土、草地分材质，不能覆盖成仓库反射地坪。
