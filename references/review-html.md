# 只核对代理没把握的事项
核对页不是全量人工审批。先利用图层、块名、尺寸、参考资产、已有确认自行识别；仅把冲突、缺证据、未知设备、会影响结果的代用/参数列为待确认。先读 [业务映射契约](business-mapping.md) 与 [用户流程](user-workflow.md)。图层分类明确不等于具体型号已确认；型号确定但缺高度仍须补录。能可靠判断的标为已识别；用户已确认记录沿用为已确认，不重复问。不要给所有对象标待确认，也不编造置信度百分比。

`python3 scripts/preview_review.py 设备清单.csv --out 识图核对.html`
必需列：编号、分组、中心X_m、中心Y_m、长X_m、宽Y_m。可选：显示编号、说明、处理、旋转_deg、来源、判断依据、不确定原因、需用户判断、问题分组。坐标统一米制 CAD XY，旋转逆时针。稳定 ID 与短显示编号的映射保留，不随重新排序变化。
处理：已识别、已确认、待确认、排除。未填写状态时保守待确认；生成前代理必须先完成分类，不能直接把未分析清单推给用户。
默认待确认视图：相关图块分类着色，其余为灰色参照；列表只列当前待确认项，显示问题类别数与涉及图块数。同类冲突合并提问，详情给出判断依据、疑点、需要用户回答的具体问题。答案与状态一起导出。可勾选同一问题且规则集、块定义/属性和适用区域一致的图块一次更新；不得把局部回答扩展到不同问题或无关区域。
支持搜索、分类开关、编号、旋转图块、缩放/平移、点击详情、状态修改与 JSON 导入导出。没有后端，修改保存在当前页面内存中，离开前导出；导入必须匹配源清单哈希和编号集合。审阅后按稳定 ID 合并到识图清单，保留原始证据及用户回答。
示例用本项目实际未决记录：26 处同位 3/4 箱位重叠合为一类问题，其余 2455 个对象不要求逐个确认。已认可的外观不等于已确认工艺；与当前布局无关的工艺流向在后续需要模拟时再询问。
HTML 核对图独立于最终三维网页；旧 preview_numbered.py PNG 继续保留。新项目先核对影响结果的未知项；已确认部分可继续推进。

新版脚本读取“生成状态/阻断原因”：即使“处理=已确认”，blocked 仍在待办中显示，原识别状态单独保留。批量核对要求规则集、规范图层、图块属性签名和确认作用域四列齐全且一致；旧 CSV 缺这些字段时仅允许逐项记录，代理仍可依据已核实的作用域合并对话答案。页面确认只保存答案，不能改写生成状态。
