# 几何、行为和交付验收

## 对照原图评估识别

分开报告：设备类别/数量、位置/方向、尺寸/高度、遗漏/多建、承载接触、功能连接和模拟行为。确定比例不等于识图准确率；无独立人工基准时不报“准确率 99%”。

从每个设备家族、不同旋转/镜像、不同建筑/楼层及待定区抽取原始 CAD 局部作为基准；模型顶视正交与同一坐标下的原图叠加检查。统计确认的错分/漏建/多建和中心/角度误差，注明样本数、分母和范围。容量标注是交叉证据之一，不能替代逐区对照。

## 实际场景检查

针对园区与建筑，检查道路/硬地/绿化语义和面积、真实网格孔洞、墙体双边线配对及重复实体。针对货架，检查首/中/尾构件、固定截面与支撑节距；不能只验证外框或源资产哈希。

本次包含货物数量、正交视图或爆炸图时，执行 [场景操作验收](scene-interaction.md)；爆炸态与复原态分开，普通工程导出保持复原布局。

- 测实际网格世界包围盒和功能点，检查单位、正交变换、有限数值、接地/嵌入、支撑所有者和活动件极限位。
- 货架层数与横梁几何一致；参数调整后高度、货物承载、轨道/提升机接口同步。
- 输送线逐段测有效长度和高度；测接缝、侧偏、端口法线。图纸机械间隙与缺陷分列，候选近邻不计为已确认物流连接。
- 反复切仓库/楼层，墙体和货物开关、暂停/倍速、背景和灯光设置；检查动态货物和实例批次残留。
- 若本次交付包含物流动画，至少跑完整取货、载货、放货循环；记录中途及末端承载者、载荷锚点重合误差、对象总数。重置后没有重复货物、离地漂移和脱离父机架。
- 真实浏览器看全景与典型接驳近景，检查报错、材质不透明和阴影；有问题就修再验。程序通过不能代替视觉复查。

接触阈值按项目展示精度配置，输入以米为单位；毫米级测试容差仅控制数值漂移，不代表 CAD/厂家工程精度。不要提高阈值去掩盖发现的 22cm 高差或 60cm 缺口。

## 检查脚本输入

`check_scene_contract.py` 接收已经从运行场景测量的**世界坐标**；Y 向上。每个 contact 可为轮胎/支脚到支撑面的采样；坡面提供实际法线。端口 normal 是面向设备外部的方向。调用：

```sh
python scripts/check_scene_contract.py measured-scene.json --out check-report.json
python scripts/check_scene_contract.py --self-test
```

```json
{
  "units": "m",
  "measurementBasis": "evaluated-world-geometry",
  "contacts": [
    {"id":"pallet-on-carrier", "subjectPoint":[0,0.8,0], "supportPoint":[0,0.8,0], "normal":[0,1,0], "tolerance":0.005, "maxLateral":0.02}
  ],
  "connections": [
    {"id":"line-a-to-b", "a":{"position":[0,0.8,1],"normal":[0,0,1]}, "b":{"position":[0,0.8,1.01],"normal":[0,0,-1]}, "maxGap":0.02, "maxLateral":0.01, "maxHeight":0.005, "angleToleranceDegrees":2}
  ],
  "viewSamples": [
    {"id":"warehouse-2-floor-2", "expectedIds":["w2f2-machine"], "visibleIds":["w2f2-machine"]}
  ],
  "cargoSamples": [
    {"id":"load-01-at-t12", "owners":["vehicle-01"], "cargoAnchor":[2,0.8,3], "carrierAnchor":[2,0.8,3], "tolerance":0.005}
  ]
}
```

`expectedIds` 来自确认的归属配置；`visibleIds` 遍历实际场景和实例可见性生成，不能从同一过滤函数各抄一份。脚本不测 GLB、不验证端口声明是否贴实际面、不确认 CAD 语义、不检查碰撞或连续路径，也不自动补缺。未覆盖类别会在报告中列为未采样，不宣称全部通过。

## 资源与发布

资产缓存与实例生命周期分离。实例删除释放自身资源，不 dispose 仍被其他实例共享的 geometry/material；参数化派生几何由创建者回收。异步重建用版本令牌丢弃过期结果并释放，旧动画不能引用新参数尚未完成的模型。按当前安装 Three.js 版本验证导出器、控件和阴影 API，不能套旧常量。

复用静态设备的 InstancedMesh，拾取保留 instanceId→稳定设备 ID；动态机构独立变换。测实际 draw calls 和渲染耗时，按需渲染静态场景、限制像素比；不要用删设备或隐藏缺陷冒充性能优化。

交付源码、独立资产/来源、布局与配置、待定清单、量化检查报告及近景截图。网页不需要原始 DXF/内部路径时不把它们放入公开静态目录。静态发布要带齐 GLB、spec、依赖、正确 MIME/相对路径；有明确既有站点时更新同一项目，保持受众配置。先执行本地检查再打包，保存版本与部署结果；终态成功后返回准确链接。没有完成部署时只称本地完成。
