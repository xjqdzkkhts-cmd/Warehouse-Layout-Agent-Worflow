# 货架构件重组与防拉伸

“高精度源 GLB”只证明来源，不能证明派生结果仍保留结构。通用搁板架也不等于智狼专用料箱架；授权同类展示代用不授权整排拉伸或忽略中间构件。

## 从 CAD 单元到构件

先识别区、排、架段、箱位/托位、层及轨道通道，保留缺口与缓存位。递归展开容器，按可见子实体分类；隐藏的动态块变体、操作员、路径点及轨道不可生成货架。去重使用完整来源和实际可见几何，不能只因中心接近删除不同工位。

建立 `rackId / rowId / bayId / levelId / slotId` 与 `partRole`：立柱、横梁、承载板/导轨、斜撑、连接件、脚板、端部附件、货物。尺寸、数量和功能依据分开记录；缓存位是否计容量需当前图纸证据。

## 允许怎样改尺寸

| 部件 | 允许的方法 | 不允许的方法 |
|---|---|---|
| 直型材 | 固定截面，局部延长无特征的直线段；孔位/连接件按节距重建 | 把孔距、脚板、端部连接随整柱拉长 |
| 横梁/承载轨 | 保留端部，调整中部跨度；按架段与层重复 | 整排仅保留首尾，横跨中间所有箱位 |
| 焊接侧框/斜撑 | 拆成柱、横撑、斜撑及连接件，按新层距重组 | 把整个侧框放大到数倍高度/双倍深度 |
| 层板 | 按有依据的箱位宽度组合承载板或轨道 | 一张大板跨过巷道、缓存位和结构缺口 |
| 料箱/托盘 | 使用合适规格；展示比例调整要统一且列明 | 为填满箱位把货物非均匀压扁或拉长 |

改变排长增加/减少架段；改变层数增加/减少横梁、支撑与承载层。双排由两个单排及明确的中间构造组成，不把单排深度直接拉成双排。源网格无法可靠拆分时，换结构合适的源件或显式参数化派生，未复原部件须列缺失，不能仅改名为“高精度智狼架”。

尺寸参数写入结构数据，网格由参数派生。完整组的 `scale` 尽量为单位变换；局部可延长构件记录 `adaptationMethod`、源尺寸、目标尺寸和固定截面。重算楼层承载面、箱位、最高层净空、轨道及提升接口。

## 全排一致的验收

- 首段、中段、末段用相同尺度检查；每个架段应有的立柱/横梁/支撑均存在。中段不能只有延伸面片。
- 测实际构件截面、连接件尺寸、孔位/支撑节距与层数；检查非均匀缩放对象及其子零件，不能只测总包围盒和总面数。
- 加一架段应出现一架段对应的构件；加一层应出现承载层及支撑，恢复参数后数量、位置和 ID 可复现。
- 容量对照按可用 `slotId` 与图纸文字独立计算；展示箱位数量不是工程容量。占用率改变只影响货物，不删除货架或把仓库拉长。
- 保留正交顶视、正视及首/中/尾近景。仅“高精度文件哈希正确”“外框落位正确”不能判为结构验收通过。

本次暴露的错误类型是：通用搁板架侧框整体拉高、双排深度拉伸。其倍率属于案例证据，不是阈值；后续应按部件是否变形判断，不靠倍率小于某个任意数自动放行。
