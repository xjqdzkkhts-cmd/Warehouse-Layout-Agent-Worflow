# 验收、分发与发布
包级：validate_bundle.py 校验三个库的 GLB/spec 哈希、ID 和引用；ZIP 解压到新目录后运行案例验收，不能依赖原作者文件夹或软链接。原库 animation-coverage.json 记录动画覆盖，不将静态结构强行动画化。
场景级：接地、承托射线、朝向、端口、占地、楼层归属、暂停、货物所有权、转向及长时间交通；案例 tools/validate.mjs、test-high-conveyors.mjs、test-navigation.mjs 为可执行回归例。新项目替换数量/高度等断言，保留几何不变量。
浏览器：总览/库房/设备，显示开关、阴影、动画暂停倍速、跟随和导出；现场截图存项目验收目录。没有实际执行的项目写未验证。
发布不绑定服务商：先查项目部署记录，更新同一站点、保留现有受众；构建源提交与包必须一致。Sites 可用时按已安装 Sites skill 的当前工具流程，不复制凭证或写死站点 ID。没有部署工具时交付 dist 静态目录和本地预览，不虚构公网地址。更改公开范围遵循用户授权。
包中不含站点身份、登录凭证、CAD 原文件或本机绝对路径。模型为用户提供资产；本包不会新增它们的第三方转授权，传播范围需遵守原资产许可。
