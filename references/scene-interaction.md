# 货物数量、标准视图与爆炸图

这些是场景交互的执行与验收要求。新建原型应提供可发现的操作入口；已有项目按本次需求接入。文档规定、示例模块存在、当前页面已实现是三个不同状态，交付逐项报告。

## 统一状态与用户流程

左侧选择园区/楼栋/楼层或对象，操作面板明确显示作用范围。货物、相机和爆炸图使用独立状态：

- 布局：稳定实体 ID、原始坐标、楼层/所有者、`restLocalMatrix`。
- 展示库存：区域、目标数量/占用率、槽位集合、随机种子及版本。
- 视图：透视/正交、方向基准、聚焦目标、墙顶显隐。
- 爆炸图：作用对象、粒度、距离与展开比例。

明确的用户操作直接执行，提供重置/撤销和结果数量。失败恢复上个有效状态并说明原因，控件不能只改变文本或保留无效按钮。渲染合批必须支持实际实例变化与拾取映射。

## 调整货物数量

先建立可承载的 `slotId / supportId / carrierId / buildingId / floorId`；货物尺寸、底面与承载面匹配，留出操作净空。没有储位数据时不能用包围盒随机撒货。

提供整数数量输入、占用率或滑块及清空/填满/重置。范围清楚显示“当前楼栋”等；数量与占用率双向更新，分母为当前明确的可展示槽位数。展示槽位、原图容量、真实库存分别标注。

0 至最大值都要有效；负数、非整数、非有限值、超过容量给出可读反馈。相同目标重复应用不得累加；使用稳定槽位顺序/种子，增减时优先保留已有货物，切换楼栋不丢其他区域配置。

CAD 固定货物、资产内置货物、可调展示货物及运输中货物分开。清空展示货物不默认删除 CAD 明确实体；设备模型若内嵌货物先拆分，否则不能声称数量可精确调节。动画执行中调整库存先暂停并稳定承载归属，不能移除正在交接的货物。

验收 0、1、部分、最大值、重复输入、非法值、切换范围与重载；遍历实际实例统计数量，检查支撑接触与重叠，而非仅比 UI 数字。

## 正视图与六向视图

“正视图”使用正交相机，不能只把透视相机转到正面。提供前/后/左/右/俯/仰及透视复位；当前方向在控件中显示。

方向基准来自项目或选中建筑/设备本地轴，明确例如“园区南向正视”；未给入口朝向时使用标注清楚的坐标基准，不声称是建筑主立面。相机 `up` 与投影面一致，避免俯仰视翻转。

按实际可见对象包围体与视口比例设置正交边界、中心和 near/far，留适当边距；缩放改变正交尺度，窗口变化重新适配。切换视图保留选中对象和库存，透视复位恢复合理轨道控制。用户可独立关闭墙/屋顶看内部，不能自动删除模型来获得无遮挡画面。

验收平行线不汇聚、前后/左右不颠倒、模型不裁切、宽高比正确，以及不同建筑和窗口尺寸下仍可使用。图片导出采用当前相机。相机切换时清理旧控制器的旋转/平移惯性，按新相机的 `up` 重建控制基准；正交视图关闭旋转，允许完整六向角度，不能继承透视模式的俯仰上限而导致正视或仰视被改写。验收应运行真实控制器的更新逻辑，不能只用空控制器桩验证相机。

## 可复原的爆炸图

区分**园区/建筑分组爆炸图**与**设备零件爆炸图**。屋顶、墙体、设备和楼板可按所属组分开；设备零件级只在已具备正确部件树时提供。不能将整机飞散称为机械装配爆炸图。

### 默认效果：纵向分层与动画

按用户明确偏好，建筑爆炸图默认采用纵向分层排布并带平滑展开/收拢动画。保持各组水平坐标对齐，沿场景竖直轴分离（标准化 Y-up 场景使用 Y）；不得默认改成墙体向左、设备向右的横向散开。

基座/首层楼板作为锚点，按真实楼层由下至上排列，屋顶置于最上方。楼层内设备、货物和附件作为所属楼层组跟随；单层建筑可按楼板、设备、墙体、屋顶分组纵向展示，不伪造额外楼层。多层建筑的墙体按真实归属分组；跨层设备保留完整形体，未具备分段依据时不强拆并列明处理方式。

按组实际包围体高度计算展开间距，保留可调净空，避免纵向展开后仍重叠；间距是展示参数，不是建筑层高。货物始终与承载设备使用同一展示变换。不同建筑分别展开，不把全园区堆成一列。

提供“展开/收拢”、展开比例、间距与“复原”控件。按钮切换使用基于 elapsed time 的缓入缓出插值，不依赖帧数；时长由当前应用配置，可从约 0.8–1.2 秒调试，不当作旧项目已核实参数。动画中再次操作从当前展示状态连续转向新目标，取消旧动画，避免跳变与多个动画争抢。拖动比例实时跟手，松手后只完成必要的平滑过渡；支持减少动态效果偏好。

动画期间保持按需渲染循环运行，结束后停止无效重绘；每帧几何变换使 AO/TAA 等缓存失效，结束后重新累积。相机按展开全过程的范围平滑适配，不逐帧突然重置用户方向；手动相机操作取消自动取景。导出先将当前展开比例稳定到明确状态再截图，不能偶然截取动画半帧；导出后恢复之前定义的状态。

追加验收：展开与收拢均有动画；纵向顺序正确且水平对齐；中途反向、快速连点和拖动不跳变；不同帧率下时长一致；减少动态效果模式可用；最终精确回到原矩阵。用户描述确立的是效果规范，未经读取旧实现不得声称动画参数与旧项目逐项一致。

每次从原始矩阵计算展示偏移，禁止在上一帧位置上累加。展开比例 0 必须精确恢复；切换楼栋、视图或导出后保持定义明确的状态。建筑之间按各自局部框架展开，不能误用同一个世界中心。

货物跟随货架/承载设备展开；楼层附件、实例批次与拾取 ID 同步。不修改 CAD 布局、工艺端口、库存和物理碰撞数据。进入爆炸模式暂停运行演示及空间编辑，退出按策略恢复；爆炸态不做接地或物流连通验收。

提供展开比例/距离、重置和“导出当前爆炸图”。普通场景 GLB 默认导出复原状态；爆炸态导出须明确命名为展示副本。截图后在 finally 恢复临时尺寸、画质与播放状态。

验收连续开关/拖动 20 次后的矩阵恢复、货物跟随、单楼栋隔离、视图切换、实际导出内容及来源布局哈希不变。浏览器不可用时几何/状态检查可先完成，交互与图片视觉验收单列未完成。

## 可复用模块及边界

`assets/scene-interactions/view-tools.js` 提供六向正交取景与基于原矩阵的分组展开/复原；`inventory-layer.js` 按调用方传入的有效槽位和模型建立可调实例货物。现有 view-tools.js 仅提供即时矩阵偏移，不自带纵向排序或时间插值动画；接入时必须按上述规则补齐，不能把模块存在当作动画已实现。两者使用项目一致的 Three.js，并不替项目识别储位、方向、承载面或拆分零件。调用方必须接入 UI、范围、错误反馈、保存、图片导出与浏览器验证。未绑定页面时不宣称按钮已可用。
