# 极简皮带输送机：连续台面与护栏

处理直线、斜坡、拐弯或螺旋皮带机时读取。当前用户的展示偏好是台面加两侧矩形护栏，不加滚筒、支腿、底架；圆角最多 1–2 段。这是用户偏好，不是所有项目的机械设计规范。用户更新要求时以新要求为准。

## 类型识别与演示取舍

设备类型与展示外形分开记录。皮带机必须有完整承载面，不能把双梁镂空模板当作皮带；明确的双链式仍保留双链特征。允许某类辊筒用链式代用，不代表整个分拣区、弯道或皮带都可以改成链式。用户后续明确要求弯道皮带化时，使用连续弧形皮带，不残留辊筒。

本用户已授权演示场景以连接流畅度优先，可调整标高、端点及螺旋结构；该偏好不表示将所有输送设备压平。先确定进料、出料和提升方向，再决定高度。施工精度任务或其他用户无此授权时，仍遵循设计标高。

## 从图纸确定路径

先解出实际台面边界、中心线、净宽、接口与标高，再生成几何。文字/属性/尺寸标注不参与设备轮廓包围盒；组合块逐个展开实际设备。不能仅凭大包围盒拟合弯道，也不能以插入点当圆心。动态块只取当前可见弧段；镜像 ARC 的圆心与端点先从 OCS 转 WCS，按 extrusion 判断转向，否则会错取隐藏角度版本或把弯道放到错误位置。

记录每段的类型、起终点、起终端切线、净宽、台面起终高度、护栏厚高；弧段另记圆心、中心线半径、起角、有符号转角；螺旋另记旋向、总转角与总高差。区分净带宽和含护栏的外宽。

沿用已确认参数。当前恒昌项目普通台面 0.8m；等腰三角形尖端是低位、底边是高位，这不是通用 CAD 约定。坡度标记可能只由两条等长线腿组成，不能只搜索闭合三角形；短流向箭头不能自动解释为坡度。三角形只确定高低方向，具体高度仍来自标高或用户确认。

## 三种生成方式

### 直线和斜坡

一张四边形台面加两条矩形截面护栏。无圆角直线基准为 1+6+6=13 个四边面，不为了长度增加沿程细分。斜坡的左右边界共用起终台面 Z；护栏跟随同一坡线，不只旋转台面。护栏高按竖直方向还是台面法向量取值，要在同一工程中统一；仓储展示优先竖直高度。平坡接口按同一断面连接，避免旋转后端头间隙。

### 平面拐弯

按内外同心弧生成连续四边面带状台面，护栏用矩形截面沿同一弧扫掠。推荐从每个 90° 弯道 6–12 段起步，按轮廓误差调整；这是沿程分段，不是圆角细分。

台面、内栏、外栏共享角度采样和端点；同一部件相邻段共享顶点。不要把独立矩形台面/长方体按圆弧逐段旋转摆放，会产生锯齿、楔形缝隙和护栏重叠。整体非等比缩放会改变带宽和圆弧，应按目标半径与带宽重建。

中心线半径 R、净宽 w 时，台面边界半径为 R−w/2 和 R+w/2，内栏内侧半径必须大于 0。若图纸表示非圆弧转接，按实际轮廓构建，不强行拟成 90° 弯头。端截面沿径向，衔接直线沿端点切线；转向不符时核对镜像和嵌套变换。

### 螺旋：默认几何节点

当前用户明确要求以后螺旋皮带机用几何节点，必须在修改器暴露 **坡度（度）** 和 **整体高度**，不得仅交付静态网格或 Screw 修改器。参考文件里的 Screw 只作为连续成型思路，不再作为本用户的默认交付方式。

整体高度定义为入口到出口的提升高差 H，不含入口离地高度和护栏；入口标高 z0 单独保留，出口 z0+H。坡度 α 定义为中心线相对水平面的角度。中心线半径 R 固定时：

- 总转角 Δθ = H / (R × tan α)，圈数 = Δθ / (2π)。
- t∈[0,1]，θ=θ0+tΔθ，z=z0+tH；台面内外边半径为 R−w/2、R+w/2。
- 台面、两侧护栏和出口接驳共用这些字段。改变高度或坡度后，圈数、出口位置与方向会变；不能同时承诺任意坡度、任意高度、固定半径与固定出口。
- 明确“向上”的物流方向：从低位入口沿螺旋上升至高位出口。不要为接回原线而擅自改成上升后下降。CAD 圆圈若只是设备位置示意，用户允许时按接口需要调整结构，不照抄圆形轮廓。

使用 `scripts/gn_spiral_conveyor.py` 的 `build_spiral()`。它在 Blender 内建立真正的字段驱动节点组，保持四边面台面及护栏，包含两端接驳；不删除其他对象，不自动保存。用 importlib 或把 skill 的 scripts 目录加入 sys.path 后调用：

```python
from gn_spiral_conveyor import build_spiral
obj = build_spiral(
    origin=(0, 0, 0.8), rotation=0,
    height=1.6, slope_degrees=13.5084029265,
    radius=1.06, width=0.68,
    inlet_length=1.3, outlet_length=1.8,
)
```

这些数字只是示例，不是所有项目的默认标高。origin 是螺旋低位口中心，不是圆心；入口接驳沿局部 +X 向外延伸，入料沿 −X，螺旋从俯视逆时针上升。对象绕 Z 旋转可整体定向。此脚本暂不暴露旋向/起角参数，不得声称已实现；需要其他旋向时扩展节点并复验法线，不直接负缩放冒充。

可调参数包括坡度、整体高度、中心半径、皮带宽度、护栏高厚、两端接驳长度。入口保持固定（在其他参数不变时），出口接驳随螺旋移动，外部产线不会自动重排。Blender 5.2 的修改器值使用 `getattr(mod.properties.inputs, socket.identifier).value`，不要把旧版 `mod[identifier]` 写法当成已生效。脚本在 5.2.1 测试，其他版本先核对接口。

生成时按圈数选择细分，默认约每圈48段；修改器调参数不会自动增加拓扑采样。参数改变到多圈时检查轮廓，必要时通过 segments 重建；不要让很低坡度配很高提升量生成欠采样螺旋。总四边面数为 9×(螺旋分段数+2个接驳段)+4，48段例为454面。圈间净空、货物尺寸和坡度合理性单独检查，能生成不等于机械上可运行。

验收至少测试两次：改变高度，验证出口Z和护栏同步；改变坡度，验证实际转角/出口位置变化、入口保持固定；恢复交付值后保存并重新打开核对。静态几何验收不等于货物仿真。

## 实例化与验收

连续皮带路径建模优先于点位实例化。点位实例 GN 可复用整台设备或完整连续线段；螺旋则用专用字段节点生成曲面，两者不可混淆。插件只有点位转换而没有连续扫掠能力时，允许用 Blender Python 建这部分几何，无需强行调用不适用的操作符。

生成后同时检查：

- 接口两侧的台面边界端点、标高、净宽、切线；按项目精度检查距离（展示可先用 1mm）与角度（可先用 1°），直坡折点可保留设计坡度差。不能只比较对象中心或包围盒。
- 台面和护栏连续，不重叠穿插；非分流接口不要加横向端挡。扫掠体端盖与护栏端挡不是同一概念。
- 相邻扫掠截面共享顶点，无重复内部封盖、退化面、自交；台面边界开放是单层面设计，不应误报为必须封闭的破洞。
- 检查上表面法线及镜像后的绕序；弯曲纵向可平滑，护栏截面棱边保持清楚。Auto Smooth 不修补真实裂缝。
- 视口和渲染采用相同沿程细分；在独立可见集合中求值，隐藏/排除集合可能返回未展开网格，不能据此统计修改器后面数。
- 分别报告基础面数、求值面数、三角面与四边面数量。Blender 主文件保留四边面；GLB 内部三角化是格式/渲染环节，不据此修改用户的主模型拓扑要求。

核对顶视的路径与轮廓，再核对侧视的坡度/高度和局部接缝。没有检查全部连接就不宣称“整线无缝”。学习参考的请求只更新规则，不自动覆盖用户参考文件或当前场景。

## 已验证的接口失败模式

本用户演示场景允许为顺接调整标高和端点；先建立相邻段接口约束，再定螺旋的起角、旋向和出口高度。明确标注开放进料端，不能把未接上的出口作为展示近似交付。

直线与弯道必须使用一致的接口净宽。护栏扫掠使用每个端点自身的横截面方向，相邻小段共用断面；用每段中点方向生成两个端面会在转弯处留下楔形缝隙。检查两侧台面边缘、护栏内外边和标高，不以中心点落入邻段轮廓替代完整接口验收。演示允许修改CAD位置时，可将相邻端点对齐，记录改变了哪些段及原因。
