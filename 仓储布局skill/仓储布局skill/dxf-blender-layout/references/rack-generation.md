# 货架与重复区域生成（几何节点）

## 规则

**重复区域必须用几何节点（GN）生成，不能逐个摆放空对象实例。** 重复区域包括：
- 立库货架排、横梁货架、搁板货架、四向车货架；
- 托盘阵列（地堆、站台、托盘架）；
- 成排的护栏、轨道、柱子等同一资产多次出现的地方。

经验阈值：同一资产在一个区域里出现 20 次以上就用 GN。

产线的输送线也用 GN（一条线一个对象，混合多种资产）。逐个空对象（集合实例）只用于零星的大设备，例如堆垛机、提升机、单台工位。

理由：
- GN 把层数、层高、总高、排深做成可调参数，改参数不用重新摆放；
- 对象数大幅减少，文件轻、视口快。本项目从 6812 个空对象降到约 200 个 GN 对象加少量空对象，而且每排、每列、每条线都能单独调整。

## 粒度：一个可独立调整的单元一个对象（用户要求）

不要把整个区域塞进一个 GN 对象，要便于人工逐排、逐列、逐线调整：

| 区域 | 一个 GN 对象对应 | 命名示例 |
|---|---|---|
| 立库 | 一排货架（XYZ 阵列） | `立库_第01排` |
| 横梁、搁板货架 | 一个连续段（XYZ 阵列，背靠背时 Y=2），同一排的段挂在同一父级下 | `横梁货架_第01排_段1` |
| 地堆托盘 | 一个矩形阵列，同一区块的阵列挂在同一父级下 | `地堆_区块01_阵列1` |
| 站台托盘 | 同一类站台一组 | `立库出入口托盘` |
| 产线 | 一条直线输送线（线上所有输送机、顶升、检测、叉车口混在一起） | `输送线_横05(y38.9)`、`输送线_纵01(x97.0)` |
| 端部附件（护栏等） | 同一类同一排布一组 | `立库端悬空护栏` |

**产线分线方法**（本项目验证过）：
1. 同一 cy（±0.1）且首尾相接（间隙 < 0.3m）的段连成横线，至少 2 段；
2. 剩下的按同一 cx 合成纵向主线，横线交叉处的顶升归横线，纵线在交叉处断开也合成一条；
3. 不超过 2 段的零散小组（检测门、叉车口等）并入最近的大组。

## 两种 GN：规则区域优先用 XYZ 阵列（用户偏好）

| 方式 | 脚本 | 何时用 | 修改器参数 |
|---|---|---|---|
| **XYZ 阵列（首选）** | `scripts/gn_xyz_array.py`，节点组 `GN_XYZ阵列` | 等距重复：立库一排、货架连续段、背靠背货架、托盘矩形阵列 | **X数量/X间距、Y数量/Y间距、Z数量/Z间距**、单元长X/深Y/高Z（0=跟随间距）、离地高度 |
| 点位驱动 | `scripts/gn_point_instancer.py`，节点组 `GN_点位实例` | 间距不规则或多种资产混排：输送线、巷道端护栏、零散站台托盘 | 竖向节数、总高、排深覆盖、离地高度 |

XYZ 阵列约定：
- 对象原点 = 第一个单元中心（底面），加数量时沿局部 +X/+Y/+Z 延伸；朝向用对象旋转（例如货架沿世界 Y 排列时 rz=90°，局部 X→世界 +Y，局部 Y→世界 −X）。
- 立库一排：X=货位数（节距 2.35），Y=1，Z=竖向节数，Z间距=节高。
- 横梁货架：一列拆成**连续等距段**（遇到缺口、单托位组或尺寸不同就断开）；背靠背两列里位置、数量、尺寸相同的段合成 **Y数量=2、Y间距=列距**，原点取 Y 方向起始的那列。同一排的段挂在父空对象 `横梁货架_第NN排` 下，方便整体选中。
- 地堆区块：分解成**最大完整矩形**（贪心：从左下角起先向 X 扩，再整行向 Y 扩），L 形区块会拆成多个阵列，挂在父空对象 `地堆_区块NN` 下。
- 资产按 单元尺寸 ÷ 资产尺寸 缩放，再按资产基点（包围盒中心 XY、底面 Z）用“平移实例（局部空间）”对齐。
- **挂父级时**：新建空对象的 `matrix_world` 在视图层更新前是单位矩阵，直接 `p.matrix_world.inverted()` 会让子对象位移被叠加两次（本项目实测，坐标翻倍）。要用 `Matrix.LocRotScale(p.location, p.rotation_euler, p.scale).inverted()`。
- 分段、配对、矩形分解用 `scripts/xyz_decompose.py`。
- 分解前后单元总数必须相等（本项目：货架 5858 = 5858，托盘 691 = 691），替换后 `instance_stats` 一致才删除旧对象，不一致就回滚（删除新对象和父空对象，恢复旧名字）。

## 做法：点位驱动的 GN（`scripts/gn_point_instancer.py`）

货架排常有缺口，比如让柱、通道、单托位组，因此**不要用“组数×节距”从起点阵列**。一律改用“图纸点位”方式：

1. **每个可调单元（一排、一列、一个区块、一条线）一个网格对象**，每个货位、托盘或设备是一个顶点，坐标来自 DXF（已做基点和资产中心补偿）。
2. 顶点属性：
   - `size`（资产局部 X 长、Y 深、总高）：按图纸尺寸逐点给；
   - `rot`（欧拉弧度）：来自块旋转和镜像。
   另有 `asize`（资产尺寸）和 `idx`（资产在资产组中的序号），所以**一个对象可以混合多种资产**，例如一条输送线里的链式机、顶升、检测门。
3. 修改器 `点位参数` 使用节点组 `GN_点位实例`，输入如下：
   - `资产组`：`GN资产组` 集合，下面是代理子集合 `NN_资产名`，每个代理包含一个从资产库链接的集合。Collection Info 的“分离子项”按名称排序，所以用两位序号前缀固定顺序；
   - `竖向节数`、`总高`：竖向叠放。总高为 0 时用每点的 `size.z`。每节高 = 总高 ÷ 节数，缩放 Z = 节高 ÷ 资产高；
   - `排深覆盖`：大于 0 时统一覆盖所有点的深度；
   - `离地高度`：整体抬高，用于悬空护栏、平台设备等。
4. 节点链：点 → 按离地高度偏移 → 按竖向节数叠成竖列 → 实现实例 → 按 `idx` 从资产组挑选实例（旋转取 `rot`，缩放为 目标尺寸 ÷ 资产尺寸）。
5. **资产尺寸必须用求值后的几何来量**。链接进来的集合里，对象的 `matrix_world` 没有经过求值（父子关系不生效），直接读会得到错误尺寸，例如堆垛机护栏读成 2×2×7.8，实际是 2.06×4.47×2.21。脚本的 `collection_size` 用临时实例测量。

API 速查：
- `ensure_asset_group(names, lib)`：链接资产，建资产组；
- `ensure_node_group()`：建节点组；
- `build_point_object(name, pts, sections, total_height, lift, ...)`：从点位新建对象；
- `empty_to_point(o)`：把集合实例空对象转成点 dict；
- `set_params(ob, 竖向节数=6, 总高=20, 离地高度=1.0)`：调参数；
- `instance_stats(objs)` 与 `same_stats(a, b)`：统计和对比实例数、包围盒。

## 参数来源（优先级从高到低）

1. 用户确认的值；
2. 图纸立面、剖面或详图；
3. 图纸文字，例如“4层横梁货架”“共3064托盘储位”；
4. 由图纸块尺寸推得，例如货位节距 = 子块间距（立库排块内子块 x 坐标差），排深 = 块包围盒宽。

以下值在没有依据时**必须问用户**，不要编造：储位层数、层高、总高。

**资产叠放 ≠ 储位层数**：资产库的货架模型自带固定层数。用“竖向节数”叠到总高时，节数只是视觉近似。要在配置里写清楚“资产叠 N 节，非图纸层数”；用户给了储位层数，再按层数调整。

## 货架相关的配套物

- 立库：巷道远端（远离输送线的一端）常有**悬空护栏**：U 形，开口朝巷道，两边卡在巷道两侧的货架面上，离地约 1m，每条巷道一个。图纸上可能画成巷道端的“单货位”或柱片小块（本项目是 `单货位` = `*U6117` 托盘垛 + `jg` 柱片），**别误读成托盘**。资产用堆垛机护栏，Y 向缩放到巷道宽，开口一侧贴住排端，**封闭一侧要越过堆垛机轨道尾端 ≥0.2–0.3m**（本项目：轨道端 −2.32，护栏到 −2.62）。判断是否罩住要看数字或真正的顶视正交图，透视图里地面轨道和离地护栏有视差，会误判。
- **提升机（换层、库前、侧向提升机）顶部要略高于货架整体高度**：一般高出约 0.5–1.5m，用来放顶部驱动和检修空间，本项目取 +1.0m。资产原高不够时按 Z 缩放；货架总高改了，提升机也要跟着改。堆垛机顶部约等于货架顶。
- 立库：堆垛机**每条巷道一台**（图纸两端各画一台时只取一台，默认放出入库端）加轨道（每巷道一条，长度盖住两端极限位 ± 约 2.5m）。巷道口站台放托盘，**储位不填托盘**，除非用户要求。
- 横梁货架：保留图纸上的缺口，不补齐；单托位组（例如 `dwef`，约 1288 长）和双托位组（约 2480）放在同一个 GN 对象里，靠逐点的 `size` 区分。
- 托盘：按图纸格子缩放到 1200×1000，旋转方向跟格子长边一致。

## 验收

替换或生成后，用 `instance_stats` 对比，或者和清单核对。混合资产的对象还要**按资产逐类核对**：统计每种资产代表网格的实例数，防止 `idx` 错位后总数不变、资产却被用错。
- 实例数 = 点数 × 竖向节数 × 资产网格数；
- 包围盒和图纸区域一致，顶部高度 = 总高；
- 改一次参数（例如节数 +1），确认实例数按预期变化后再改回。
