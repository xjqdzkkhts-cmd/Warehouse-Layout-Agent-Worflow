# 验收

用**求值后的几何**核对，不看对象属性。用户确认过语义，不等于程序验收已通过。

## 程序检查

1. **位置**：每个实例的求值包围盒中心 vs 清单中心，偏差 ≤ 项目阈值（默认 0.05m）。缩放到图纸框的设备，尺寸偏差也应接近 0；不缩放的标准件（托盘、堆垛机）要列出尺寸差。
2. **数量**：
   - 按分组比较实例数和清单数；
   - GN 对象按“点数 × 竖向节数 × 资产网格数”核对，遍历 `depsgraph.object_instances`，用 `inst.parent` 归属。
3. **高度**：货架顶和堆垛机顶都等于确认的总高；提升机顶**略高于**货架顶（约 +0.5–1.5m），低于或等于货架顶都算错；输送线台面高度一致；机构件（例如顶升）放在台面上，不悬空、不埋地。
4. **巷道**：每条轨道上恰好一台堆垛机；每条轨道至少一端被护栏在平面上完全罩住。
5. **干涉**：堆垛机和货架排的 XY 包围盒不重叠（巷道内）；输送线段首尾相接，没有大缝隙。
6. **GN 参数**：改一次参数（XYZ 阵列改 X数量+1，点位对象改竖向节数+1），确认实例数按预期变化后再改回。

## 视觉检查

- 导入平面底图（插件 `wh.import_underlay`），开对照模式（`wh.compare_mode`）截顶视正交图，模型和底图线应当重合；再放大一处典型区域核对细节。没有插件时，用编号预览 PNG 对比。
- 透视近景看一处典型区域，例如立库出入库端：设备朝向、托盘位置、有没有悬空。

## 交付

- 保存为新的 `.blend`，放在输出目录。资产库用相对路径链接，并说明两个目录需要保持相对位置。
- 在交付说明里写明：
  - 生成了什么、各用了哪个资产、哪些是代用；
  - 所有非图纸依据的假设（例如叠放节数）；
  - 没有生成的内容和原因；
  - 检查结果（数字）。
- 更新 `project-config.json`，写入已确认的参数和跳过的项目。
