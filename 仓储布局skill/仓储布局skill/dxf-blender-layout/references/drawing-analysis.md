# 图纸分析（首次走查）

配合 [warehouse-patterns.md](warehouse-patterns.md) 使用：那份讲“这通常是什么”，本文讲“怎么把它读出来”。

## 环境

- 用 `ezdxf` 解析。系统 Python 常没装，就在临时目录建 venv：`python3 -m venv <scratch>/venv && <scratch>/venv/bin/pip install ezdxf matplotlib`。
- 100MB 级 DXF 读取约 10 秒。每一步的结果（插入清单 JSON、预览 PNG）都存起来复用。

## 步骤

1. **总体统计**：`dxf_inventory.py stats`。
   - 看单位（`$INSUNITS`，4=mm）、实体类型、图层数量排行、块使用排行（含动态块原名）。
   - 范围异常大（例如几百公里）说明模型空间里散落着多份视图或远处的杂物。
2. **找视图分块**：`scatter` 画顶层实体中心，找出几个密集簇。
3. **认楼层**：`texts --region` 按字高降序列出文字。
   - 先看大字：区域名、容量、“1F/2F”；
   - 同一设备（例如堆垛机）在多个簇的相同相对位置出现，说明是贯通设备。
4. **渲染目标楼层**：`render --region` 先全景再局部，人工看一遍布局。
5. **提取插入**：`inserts --region … --out f1_inserts.json`，得到每个插入的句柄、块名、动态块原名、图层、插入点、旋转、镜像、求值包围盒。
6. **分组**，判断顺序：
   1. 先排除：楼层范围外、别的楼层图层、标注类（标高、BCR、文字组）、图框外副本；
   2. 再按“动态块原名 → 块名 → 图层 → 包围盒尺寸”聚类；
   3. 用 warehouse-patterns 猜含义，看不懂的打开块内容：`doc.blocks.get(name)` 统计子实体和子块、读块内文字。
7. **检查副本**：同一组块在两个位置各有一套，坐标差一个常量，就只保留主图那套，另一套写进排除清单并注明偏移。
8. **找高度**：
   - 立面、剖面视图、标高文字、高度标注（`H=…→…`）；
   - 平面图读不出储位层数和层高时，集中问用户。

## 坐标

- 选一个区域角点作为原点，例如立库左下角的 DXF 坐标，mm 换算成 m。原点写进 `project-config.json`。
- **位置用求值包围盒中心**，不用插入点，因为块基点常常不在几何中心。朝向用 `layout_math.py`，由插入旋转、镜像和嵌套矩阵推出。判断设备朝向时，要看块内不对称的特征，例如堆垛机电控柜所在的一端。

## 输出

中间结果（统计、文字、渲染、`<楼层>_inserts.json` 等）都存进 `输出/识图确认/_过程/`，复用不重算。给用户的文件和命名见 [csv-confirmation.md](csv-confirmation.md) 的“输出目录”，不要在它规定之外往顶层加文件。
