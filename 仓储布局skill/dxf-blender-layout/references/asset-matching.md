# 资产匹配

## 读取资产库

- 资产库路径：Blender 偏好设置 `filepaths.asset_libraries`，或者用户直接给的 `.blend`。
- 用后台 Blender 检查，不打扰用户当前场景：`Blender -b 库.blend --python inspect.py`。
  - 列出 `asset_data` 不为空的集合；
  - 按**求值网格包围盒**记录尺寸、最小和最大角（原点偏移）、朝向特征，例如哪一端是电控柜、载货台，长边沿哪个轴。
- 结果存成 `assets.json` 复用。

## 匹配原则

1. 以用户确认为准；其次看名称或语义（动态块原名、图层）；尺寸只做核对，不能单凭尺寸认定。
2. **缩放**：
   - 用户同意缩放时，把资产缩放到图纸包围盒；长度方向用**长度最接近的型号**再缩放，少变形（例如链式机有最短、中、中长、长、最长几种）；
   - 标准件（托盘、堆垛机、人员工位）优先保持比例，只做小幅缩放。
3. **没有对应资产**：可以借用外形相近的资产并注明“代用”（例如滚筒线用链式机代），或者用简单几何体，或者先不生成。选哪种由用户定。
4. **设备只有机构、没有机架**（例如顶升移栽只有 0.15m 高）：下面垫一个缩放过的输送机当机架，自身放在台面高度，注明组合方式。
5. **链接，不导入**：`bpy.data.libraries.load(path, link=True)` 链接集合，用相对路径保存，并记录资产依赖。
6. **Z 值**：对齐底面或承载面。资产原点不一定在底面，要用包围盒的最小 Z 核对。

## 常见对应（示例资产库）

| 图纸 | 资产 |
|---|---|
| 堆垛机 | 自研单立柱或双立柱堆垛机，另加堆垛机轨道 |
| 立库货架排、横梁货架 | 横梁货架（GN 叠放或缩放） |
| C-双链式输送机 | 链式机系列 |
| LK-滚筒输送机 | 链式机代用（需确认） |
| 托盘滚筒顶升 | 顶升移栽，加链式机机架 |
| 提升机、SSH-提升机 | 提升机（Z 缩放到货架总高再加约 1m） |
| 尺寸检查器 | 外形检测 |
| 叉车口辊筒 | 牙叉辊筒输送机 |
| 托盘 | 蓝色托盘+货物，或木托盘货物堆（按用户选择） |
| 四向车库 | 四向车货架、自研四向车、库前换层提升机 |
| AGV | 海康托盘AGV、潜伏式AGV，以及对应充电桩 |
