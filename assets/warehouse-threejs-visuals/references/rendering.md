# 渲染实现与固定基准

## 复用原则

优先复用 `assets/viewer-template/src/`，不根据截图重新猜一套灯光和着色器。
视觉规则在网页层生效，源模型、业务规格及布局独立保存。
下面的值是当前可复现的美术基准，不是材料实测或照度设计值。

## 技术栈与通道

- Three.js 0.180.0，WebGLRenderer，GLTFLoader，OrbitControls。
- ACES 色调映射、sRGB 输出。颜色位图使用 sRGB，法线、ARM、磨损图不做颜色转换。
- 主链：StableTAARenderPass → WarehouseAOPass → UnrealBloomPass → OutputPass → FXAA。
- TAA 只在静止时累积 32 个样本，无运动重投影。移动时使用单帧及 FXAA。
- HDR 用 PMREM 预滤波；不是实时反射周围全部设备，也不是多次反弹全局光照。
- `onBeforeCompile`、ShaderChunk 和 GTAO/TAA 内部适配依赖锁定版本。不要直接升级库。

## 材质角色

角色来自 `materialBindings` 或资产材质 extras 的 `materialRole`。
项目映射优先；已有贴图和特殊光学材料优先保留；未知材料保持原样。

| 角色 | 表面类别 | 金属度 | 基础粗糙度 |
|---|---|---:|---:|
| galvanized | 金属 | 0.92 | 0.33 |
| stainless | 金属 | 0.96 | 0.22 |
| powderCoat | 喷粉涂层 | 0 | 0.38 |
| enamel | 漆面 | 0 | 0.29 |
| plastic | 塑料 | 0 | 0.42 |
| rubber | 橡胶 | 0 | 0.68 |
| cardboard | 纸箱 | 0 | 0.86 |
| concrete | 水泥 | 0 | 0.72 |
| wall | 墙面 | 0 | 0.80 |

涂层分别使用 0.16、0.32 清漆强度。纸箱镜面强度 0.35，橡胶 0.5，塑料 0.8。
资产原始颜色保留；只有明确的 `materialColors` 才覆盖线性 RGB。
不要复制参考场景中特定名称的颜色修正。

基础库六类表面各含颜色、OpenGL 法线和 ARM，共 18 张位图。
ARM 的 RGB 分别是 AO、粗糙度、金属度。实际文件和来源见模板的第三方清单。
三向投射以米为尺度：水泥约 3 米、金属 0.7 米、涂层 0.18 米、
纸箱 0.3 米、橡胶 0.14 米、墙面 0.6 米。实例矩阵参与世界位置计算。

程序化层叠加镀锌斑纹、方向性细纹、涂层微粒、纸箱纤维等弱变化，
只改变粗糙度和少量底色，不增加几何。新增细节的对象局部坐标考虑实际缩放；
用屏幕导数过滤远处的亚像素高频纹理，不用帧时间产生随机变化。
方向性细纹不是完整的各向异性 BRDF。已有世界投射位图也不等于完整动画材质方案。

## 地坪与反射

地坪为连续水泥，不默认加网格、分缝、积水或浓雾。
运行时按项目范围生成磨损图，R 为磨亮、G 为斑驳、B 为轻微擦痕。
只有提供确认的通道才生成通道磨亮；没有通道时不发明物流轨迹。
固定种子保证相同输入可重现。

粗糙度与地面反射共用磨损分布，避免颜色磨损在一处、反光在另一处。
地面反射使用镜像相机的 Reflector，不是 SSR。平面高于地坪约 1.5 毫米，
透明混合、关闭深度写入，并在 AO 的替代材质阶段跳过反射捕获。
粗糙区更模糊且更弱，磨亮区更清晰，叠加掠射角变化。
这仍是近似方案，不是全场景路径追踪。

## 光照与阴影

环境采用随包提供的仓库 HDR。三种灯光模板参数在 `project.mjs`。
自然日光使用投影方向光和半球补光；关闭屋顶时启用外部面积补光。
预览建筑封闭时，环境及补光按模板降低；这是展示补偿，不是从窗洞求解真实间接光。

吊灯数量按建筑长宽、目标间距及 `maxLights` 生成，不固定使用参考仓库灯位。
面光源负责照明，发光材质负责可见灯面，辉光负责高光外溢，三者分开控制。
最多两盏固定在项目空间的辅助聚光灯提供室内投影；它们不随相机移动。
RectAreaLight 本身不产生阴影。模型位置变化后需要刷新相应阴影。

方向光阴影范围包住设备与外壳。PCSS 风格滤波使用 12 次遮挡物搜索、20 次滤波，
采样范围随场景尺度调整；不是 CSM。大范围、多建筑需要另行设计阴影预算。

## AO 与静止缓存

默认 AO 半径 0.45 米、强度高档 0.65，中档 0.60。
厚度为 `clamp(radius * 0.55, 0.08, 0.5)`；
去噪 depthPhi=0.3、normalPhi=8、lumaPhi=8。
高/中/低 AO 使用 24/12/8 个样本，约 0.8/0.55/0.4 渲染尺寸。
移动时可保留最多 0.4 尺寸和 8 个样本，物理半径与强度不突变。

AO 深度阶段排除反射辅助面、普通透明面和灯具发光面。
稳定相机的结果在 TAA 累积期间复用；任何相机、几何、显隐、参数或尺寸变化均使缓存失效。
EffectComposer 会把通道尺寸改为主画布尺寸，因此必须独立重新应用 AO 尺寸预算。
不要只检查配置值，还要检查实际 AO 渲染目标宽高。

## 画质与交互

具体参数以 `quality-settings.mjs` 为单一来源。高档开启全部兼容的主要效果，
中档保留基本写实表现，低档仍保留 PBR、基础阴影，但关闭高成本可选效果。
预设不修改场景操作。手动改项立即进入自定义，并可恢复上次组合。
浏览器存储受限时仍可操作，只是不保证跨刷新记忆。

移动时暂停平面反射、辉光和静止累积；AO 是否保留由单项设置决定。
相机停止约 150 毫秒后恢复静止状态。导出等待静止累积完成。
静止按需绘制，不能用静止缓存帧的提交耗时推算漫游 FPS。

## 实例化与资源

同一几何、同一材质、相同投影属性的合格重复对象达到 3 个时合批。
跳过骨骼、变形、透明、多材质、负变换、已有实例、含子节点或隐藏对象。
保留实例名称和资料，核对世界矩阵及范围。
GLB 的 GPU 实例扩展可加载；统计源面数时必须乘实例数量。

独立重复网格的离线去重、几何编码和纹理 GPU 压缩可作为后续资源准备步骤，
但不能为了缩小文件删除必要 UV、法线、业务标记或改变设备尺寸。
本包没有自动减面、LOD、分区流送或大场景遮挡系统。
