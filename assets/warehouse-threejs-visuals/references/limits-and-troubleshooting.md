# 边界与故障处理

## 已实现与未实现

已实现：角色化 PBR、程序化细节、HDR 环境、方向软阴影、有限室内投影、
GTAO 与静止缓存、粗糙平面反射、32 样本静止 TAA、画质预设与自定义、
基础建筑外壳、按配置的地坪磨损、兼容对象实例合批。

未实现：CAD 自动识别、原生 Blender/UE 生成或同步、SSR、完整实时 GI、
局部反射探针、烘焙管线、体积光、自动 LOD、园区分区流送、
碰撞漫游、资产编辑器和真实物流动画。
不要因为这些方案曾被讨论，就将它们标成当前技能已有能力。

## 常见问题

| 现象 | 首先检查 |
|---|---|
| 新场景像灰模 | 材质角色是否已绑定；源材质是否为 unlit；贴图是否成功加载 |
| 金属过黑或涂层发白 | 材质角色、基础色、环境强度、曝光、色彩转换；不要统一加亮颜色 |
| 地面移动时大片闪烁 | 旧地坪是否因节点改名漏隐藏；是否有多个同高度实体面 |
| 地面像镜面水池 | 磨损范围、粗糙度和反射强度；不要全地面降低粗糙度 |
| AO 产生大黑边 | 半径、厚度、去噪边缘阈值；透明/反射辅助面是否被当成实心对象 |
| 静止正常、移动异常 | 运动降档、采样失效、细纹过滤、阴影刷新和实际连续帧 |
| 切换设置后 AO 变慢 | 实际 AO 渲染目标是否被主画布尺寸覆盖；缓存是否反复失效 |
| 更换模型后镜头看不到主体 | 单位、场景范围、相机配置及已有建筑遮挡；不要先移动设备 |
| 实例位置或数量异常 | 实例矩阵、父级缩放、镜像、共享几何与业务 ID；不要靠整体平移掩盖 |
| GLB 需要解码器 | 检查 Draco/Meshopt/KTX2 扩展；模板未配置，不自动假装支持 |

## 不应采用的“修复”

- 不以删除设备、移动建筑、填平洞口或重复地坪让截图看起来正常。
- 不以无光照材质、全场发光或极端曝光掩盖法线/材料错误。
- 不给所有设备套同一个金属度，也不把品牌纹理覆盖成程序噪声。
- 不把实例化当作消除所有几何成本；全仓库一个批次还会限制空间剔除。
- 不在大模型加载时临时重写完整减面流程，或为“高画质”关闭所有预算约束。
- 不把输入图像中的设备补画到模型，正式截图必须来自实际场景。

## 迁移或修改后的停止条件

发现单位、布局、地坪身份、材质角色或项目范围存在实质歧义时，先停在可恢复副本上确认。
脚本或导入失败后先检查已经发生的副作用，不重复生成叠加对象。
不能用当前包的检查通过，替代新场景、不同引擎版本或不同硬件的验证。

技能包内参考图只用于内部对照，不应当作可自由分发的客户模型资产。
PBR 资源及第三方代码的许可清单与上述参考图许可范围分开。
