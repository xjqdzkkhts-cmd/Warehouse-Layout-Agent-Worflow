# 仓储/产线图纸经验参考

用途：首次走查时帮助**猜测**块或区域的含义，并在回查时提示遗漏。这里全是经验，不是规则。任何一条都要有项目依据（块名、动态块原名、图层、文字标注、尺寸、位置关系）才能写进清单；依据不足就标“待确认”并问用户。不要因为“这里通常有 X”就凭空生成 X。

尺寸均为常见范围，单位 mm。

---

## 1. 读图先看的东西

| 线索 | 能说明什么 |
|---|---|
| 大字号文字（h≥500） | 区域名称和容量，例如“横梁货架存储区，4层，368+30组，共3064托盘储位”“收货及待验区349个托盘位”“地堆位1117个”。通常最先提供层数、数量和区域边界。 |
| “1F/2F/3F”，“2F 100个复核台”等 | 楼层归属。同一 DXF 常把各层平面在模型空间里上下或左右排开。 |
| 图层名 | 常带楼层、系统和期次，例如 `1F托盘线一期`、`2F补货线`、`SSH_搬运系统`、`设计-立库箱线`。区分设备的效果往往比块名更好。 |
| 动态块原名 | 匿名块 `*U123` 的原名，例如 `C-双链式输送机`、`LK-滚筒输送机`、`托盘滚筒顶升`、`尺寸检查器或LED支架`。可以用 `dxf_inventory.py` 解析。 |
| 高度标注 `H=3000→H700`、`700→2300`、`2800→1000` | 输送线标高变化（mm），表示爬坡、下坡、提升机或螺旋。数字是台面高度，不是设备高度。 |
| `LED`、`BCR`、`读码器`、`扫码` 小文字或小块 | 输送线上的显示屏和读码点，多数是附属标注，不必单独建模。 |
| 标高符号块（图层 `0-标高`、`DIM_ELEV`） | 标注，不是设备，按包围盒看可能很像小设备。 |

## 2. 自动化立体库（托盘 AS/RS，堆垛机库）

**图上的样子**
- 一组**很长的平行细长矩形**，每排常是一个整块，块里是按货位节距重复的子块，常见带对角叉线或托盘方框。排长可达几十到上百米，排深约 1000–1400（单深）。
- 两排之间是巷道，宽约 1200–1600。两排紧贴、中间没有巷道，说明是**双深位**。
- **堆垛机块**画在巷道里，常在**巷道两端各画一个**，表示行走的两个极限位。**实物是每条巷道只有一台**，只生成一台，默认放在出入库端（靠输送线）；要放在巷道中间演示时再调位置。
- 巷道中线常有轨道线；排的两端有库位编号文字（例如 `1-01`）。
- 立库贯穿多层时，每一层平面图的同一位置都会重复画出立库，这正是判断“贯通货架”的依据。

**旁边通常有什么**
- **库前端（出入库侧）**：
  - 输送线矩阵：链式输送机（托盘横向输送，块宽约 1300、长 1900–4500）、滚筒输送机（宽约 1350）、顶升移载（约 1240×1350，位于输送线交叉和转向处）。
  - 出入库站台：巷道口的单货位、托盘垛。
  - 入库口：外形检测或尺寸检查门架、BCR、LED 屏。
  - 空托盘叠盘机或拆盘机、牙叉辊筒输送机（叉车取放口），多楼层时还有提升机。
- **库尾端（远离输送线的一端）**：检修位、维修通道、安全门。常见**每条巷道一个的悬空护栏**：U 形，开口朝巷道，离地约 1m，宽度等于巷道宽（约 1.5m），伸出排端约 2m，用来罩住堆垛机端部。**护栏在平面上必须把堆垛机轨道的尾端完全罩住**：长度 = 排端到轨道端的距离 + 余量（≥0.2–0.3m），不能只按图纸块的尺寸。图纸上它可能画成巷道或排端的“单货位”、托盘垛或柱片小块，按块名很容易误读成托盘。遇到排端或巷道端的小块，优先怀疑是护栏或检修设施，要问用户，或者对照效果图、参考图确认。
- **高度**：一般 15–24m，堆垛机高度约等于货架高度，**库前提升机或换层提升机要略高于货架**（约 +0.5–1.5m）。**平面图里基本没有层数和层高**，要找立面或剖面，或者问用户，不要编造。

## 3. 横梁货架区（叉车作业的选取式托盘货架）

**图上的样子**
- 以**货位组**为单元的小矩形，排成背靠背的双排，排间是叉车巷道（2800–3500，窄巷道约 1600–2000）。
- 单组常见梁长 2300 或 2700（每层 2 托），或 1300 左右（每层 1 托）。深 900–1100。块内常是“横梁”加“柱片”子块，块名可能直接就是梁长（例如 `2300`）。
- 排中间出现缺口、单托位组或更短的组，通常是在让开柱网或消防通道，**不要补齐**。
- 标注常写“N层横梁货架、X组、共Y托盘储位”，可以用来反算层数：储位 ÷ 组 ÷ 每层托数。

**旁边通常有什么**
- 拣选投线位和拣选输送线（常画成虚线或点划线，带分支）。
- 叉车或前移式叉车通道、防撞护脚、端部护栏。
- 收货暂存或地堆区。
- 顶层上方可能有消防喷淋，平面图通常不画，不用建。

## 4. 地堆 / 收货待验 / 发货暂存区

**图上的样子**
- 托盘方格阵列：单元约 1300×1100 或 1200×1000（托盘本体 1200×1000，加间隙）。成块排列，块与块之间留通道。
- 有容量文字，例如“地堆位1117个”“收货及待验区349个托盘位”。

**旁边通常有什么**
- 月台和卸货门（外墙一侧，门宽约 3000）、升降平台、叉车和地牛。
- 发货区旁常有集货区和打包缠膜。

## 5. 拆零 / 搁板货架区（件拣）

**图上的样子**
- 大量小矩形：1500–2000 × 500–600，多排密集。图层或块名常带“隔板”“搁板”“拆零”。

**旁边通常有什么**
- 周转箱输送线（宽 500–700）、拣选工位、电子标签（PTL）、料车、补货线。
- 有“隔板货架N组，每组M件”这类标注。

## 6. 箱式输送 / 复核打包 / 分拣产线区

**图上的样子**
- 细长的输送线段（箱线宽 500–800），常用动态块，名称带“辊筒”“皮带”“链式”，带箭头或高度标注。
- 工位块成排出现：复核台（单工位或双工位，数量常在大字里给出，例如“2F 100个复核台”）、打包台（约 2500×1100）、自动开箱机、封箱机、贴标机。
- 扫描设备：六面扫、顶部群扫、侧扫、称重（在输送线上，文字写“条码扫描”“订单条码扫描”）。
- 分拣机：长主线加两侧等距的格口或滑道；格口末端有笼车或周转箱。
- 螺旋输送机：圆形或多圈弧线组成的独立块，直径约 2000–3000，负责跨楼层输送。
- 提升机：方形块约 2000–3000，多楼层同一位置重复出现。**高度：提升机顶部略高于货架整体高度**（约 +0.5–1.5m，顶部有驱动和检修空间）。它服务于最高层货位或最高楼层，比货架矮是不合理的。

**旁边通常有什么**：空箱线、补货线、待复核线、出库线（图层名常直接这样写）；电控柜；安全护栏；人行通道。

## 7. AGV / 四向车 / 穿梭车区域

**图上的样子**
- AGV：虚线或点划线路径网格，有转弯弧；小矩形车体（潜伏式约 1000×800、托盘搬运式约 1800×1200）。**边缘**有充电桩的小块。
- 取放点有托盘架（单层，约 1400×1250）。
- 四向车库：密集的货位格加纵横轨道线，端部有换层提升机，货架边有四向车块。
- 穿梭车：巷道内沿轨道，库前有提升机和接驳输送线。

**经验提醒**：产线区可能有 AGV、单层托盘架、托盘和边缘充电桩，但不是每个项目都有。不要默认给每台车配托盘，也不要把储位填满。

## 8. 建筑与辅助

- 轴网（图层 `AXIS`/`J-AXIS`）、柱子（小方块，约 600×600）、墙体、防火卷帘、电梯（约 3700×3200）、楼梯、办公区。默认不建，除非用户要求。
- 详图、材料说明（例如幕墙节点“铝合金立柱”“玻璃压板”）、图框和签名层（`GGSignatureLayer`）都是非设备内容。

## 9. 本类图纸的常见陷阱（实例积累）

1. **多楼层并排在同一个模型空间**：先用散点图找簇，再用大字“1F/2F…”和立库重复位置判断楼层。
2. **图框外的整套副本**：例如 `1F托盘线一期/二期` 在主图左侧约 193m 外有一份完整副本，现场位置用的是 `托盘（新）` 图层。判断方法：同一组块名、数量相近、坐标整体差一个常量偏移。只取主图里那一套。
3. **别的楼层图层混进本层范围**：例如 1F 区域里出现 `天狼3层出库线`、`W2F-…`、`2F补货线` 的块，默认排除，或者问用户。
4. **组合块**：例如 `单货位` = 托盘垛 + 其他子块。只生成一层，不要父子都生成。
5. **标注块看起来像设备**：标高符号、`BCR` 标签块、`发货分拣` 这类大范围标注组。
6. **堆垛机两端各画一台**：只是行程极限位示意，每条巷道只生成一台（本项目 20 个块 → 10 台）。
7. **动态块 `*U`**：同一原名下有很多个 `*U`，尺寸各不相同（输送线长度不同）。按原名归类，按实际包围盒取尺寸。
8. **立库尾端的“单货位”其实是护栏**：本项目的 `单货位` 块（托盘垛 + `jg` 柱片）在排端出现 28 次，实物是每条巷道一个的悬空 U 形护栏（10 个）。**块的数量和位置不一定等于实物的数量和位置**，有参考图或效果图时一定要对照。
9. **建筑墙体藏在绑定的外部参照块里**：本项目整栋建筑（各楼层的墙、柱、门窗，外加图框）是一个插在原点、名叫 `土建` 的巨型块，图层名形如 `AX-01-Plan.dwg-…$0$J-WALL`。按块的整体包围盒筛选区域会把它整个丢掉，必须递归拆开，只取区域内的部分。插件的底图导入已经这样处理。
10. **块的旋转和镜像**：例如堆垛机块 `rot=90, sx=-1`，局部 +Y 对应世界 -X。朝向要用 `layout_math.py` 推算，不要只看旋转角。
